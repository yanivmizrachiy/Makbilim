# Makbilim — זוויות בין ישרים מקבילים

פרויקט ליצירת חוברת דפי עבודה מקורית, מדורגת ומקצועית בנושא זוויות בין ישרים מקבילים.

> **מקור האמת היחיד והמחייב של הפרויקט הוא [`SPEC.md`](./SPEC.md).**
>
> אין להוסיף דרישות מחייבות ל-README, לקוד, ל-JSON, ל-Issues או למסמכי תיעוד אחרים. כל דרישה חדשה נכנסת קודם ל-`SPEC.md`, ורק אחר כך מיושמת.

## בידוד תפעולי מוחלט

הריפו הזה מיועד **אך ורק** לפרויקט "זוויות בין ישרים מקבילים".

- GitHub: `yanivmizrachiy/Makbilim`
- ענף עבודה ראשי: `main`
- עותק מקומי ייעודי: `Desktop\Makbilim`
- אין להכניס לכאן קוד, מסמכים, נכסים, משימות או דרישות מפרויקט אחר.
- אין לבצע עבודה של פרויקט אחר מתוך תיקייה זו.
- סוכן AI או כלי אוטומציה שמזהה בקשה שאינה שייכת לישרים מקבילים צריך לעצור ולא לשנות את הריפו.
- `SPEC.md` נשאר מקור האמת היחיד לדרישות המוצר; סעיף זה מגדיר רק את גבול הפרויקט והתפעול שלו.

הפרויקט מיועד להפקת דפי A4 ברמת ספר לימוד, עם עברית RTL תקינה, כתיב מתמטי מקצועי, שרטוטי SVG וקטוריים, מדרג דידקטי, מניעת כפילויות ובדיקות אוטומטיות.
